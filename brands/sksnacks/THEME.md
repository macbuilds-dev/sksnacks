# SHSnacks Kitsch theme

Intentional "bad taste" with a wink: roadside Lahori snack banners x
90s gift-wrap x comic-print stickers.

## References
- Maximalist pop / Memphis clash (hot pink + mint + lemon slabs)
- Comic / Ben-Day halftone backgrounds
- Thick ink borders + hard offset shadows (sticker / die-cut feel)
- Retro display type (chunky, slightly outdated)
- Excess badges, bursts, rotated chips

## Palette (brand.yaml)
| Token | Role |
|-------|------|
| primary `#FF2D95` | Magenta plastic |
| secondary `#00D4C8` | Electric mint |
| accent `#FFE600` | Chrome lemon |
| background `#FFE8F5` | Candy wash |
| surface `#FFFDF5` | Glossy stickers |
| outline `#11080C` | Ink keylines |

## Rules
- Clash on purpose; do not "harmonize" into soft pastels
- Borders >= 3px, shadows hard (no soft blur elevation)
- Brand name reads as a hero signal on home
- One job per section; excess is decorative, not cluttered data
- Change hex in `brand.yaml` and hot-restart; theme rebuilds from YAML
